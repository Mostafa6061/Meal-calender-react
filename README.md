# 🍽️ Meal Calendar

**Meal Calendar** is a simple and interactive meal planning web app that allows users to drag and drop meals into a weekly calendar layout. It helps users stay organized and plan their meals efficiently.

## 📦 Features

- 🗓️ Weekly meal planning interface
- 🥗 Drag and drop meals into calendar boxes
- 💾 Responsive and easy-to-use UI
- 🌐 Ready for deployment with Vercel

## 🛠️ Tech Stack

- **React** – Frontend framework
- **CSS** – Styling the layout and components
- **Vercel** – Deployment platform

## 🚀 Getting Started

To run the project locally:

```bash
git clone https://github.com/your-username/meal-calendar.git
cd meal-calendar
npm install
npm run start
